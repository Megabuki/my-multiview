1. 수집하는 사용자 데이터

My MultiView는 아래 데이터를 처리합니다.

  • 인증 정보: 치지직 채팅에 로그인된 상태로 참여하기 위해 치지직·네이버 세션 쿠키를 사용합니다.
  • 개인적인 커뮤니케이션: 채팅 메시지를 읽어 여러 방송의 채팅을 한곳에 모아 보여주고, 블라인드 처리된 메시지의 원문을 복원하고, 채팅 내용을 기기에 저장합니다.
  • 웹사이트 콘텐츠: 방송 제목, 채널 정보, 채팅 텍스트 등 치지직 페이지의 내용을 읽어 멀티뷰 화면을 구성합니다.

2. 데이터 이용 목적

위 데이터는 멀티뷰 시청 기능 제공에만 사용합니다. 다른 목적으로 사용하지 않습니다.

3. 데이터 저장 및 전송

설정, 즐겨찾기 목록, 채팅 저장 내용은 사용자의 기기(브라우저 저장소)에만 저장되며, 개발자의 서버로 전송되지 않습니다. 단, 치지직 서비스를 이용하는 과정에서 해당 데이터가 치지직·네이버 서버와 주고받아질 수 있습니다.

4. 제3자 제공 및 판매

사용자 데이터를 제3자에게 판매하거나 제공하지 않으며, 광고 목적이나 신용도 판단·대출 목적으로 사용하지 않습니다.

5. 데이터 삭제

확장 프로그램을 삭제하면 기기에 저장된 데이터가 함께 삭제됩니다.

6. 방침 변경

이 방침이 변경되면 이 페이지에 변경 내용을 게시합니다.
