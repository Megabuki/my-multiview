# My MultiView

여러 치지직(CHZZK) 방송을 한 화면에서 동시에 보는 개인용 크롬 확장 프로그램입니다.

> 비공식 개인 프로젝트입니다. 치지직·네이버와 관련이 없습니다.
> CZ MultiViewer 등 기존 확장 프로그램에서 아이디어를 얻어 새로 만들었습니다.

## 주요 기능

- 여러 방송을 한 화면에 칸으로 배치, 드래그로 순서 변경
- **크게 보기**: 한 칸을 크게, 나머지는 작은 창으로. 큰 칸의 소리만 켜짐
- 마우스를 올린 방송만 소리 켜기, 전체 음소거
- 채팅 모아 보기 (종류별 숨기기, 뱃지 제거, 유저 고정)
- 광고 중 자동 음소거, 끝나면 원래 소리로 복원
- 즐겨찾기 방송 시작·종료 알림, 칸별 밝기·대비 필터

## 설치 방법

스토어에 올라가 있지 않아서 **개발자 모드**로 설치합니다.

1. 오른쪽 **Releases**에서 최신 `my-multiview.zip`을 받아 **압축을 풉니다.**
   압축을 푼 폴더 안에 `manifest.json`이 바로 보여야 합니다.
2. 크롬 주소창에 `chrome://extensions`를 입력해 확장 프로그램 페이지를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. 아래 둘 중 편한 방법으로 폴더를 추가합니다.
   - **압축해제된 확장 프로그램을 로드합니다**를 누르고, 압축을 푼 폴더를 선택
   - 압축을 푼 **폴더를 그대로 확장 프로그램 페이지에 드래그 앤 드롭**
5. 목록에 **My MultiView**가 나타나면 설치 완료입니다. 퍼즐 모양 아이콘에서 고정해 두면 편합니다.

설치한 폴더는 지우거나 옮기지 마세요. 크롬이 그 폴더를 직접 읽어서 실행합니다.

### 업데이트하기

새 버전을 받아 **같은 폴더에 덮어쓴 뒤**, `chrome://extensions`에서 My MultiView의 새로고침 버튼(↻)을 누릅니다.

## 알려진 점

- 치지직 페이지 구조가 바뀌면 일부 기능이 동작하지 않을 수 있습니다.
- 크롬(Chromium 기반 브라우저)에서만 확인했습니다.
- 직접 쓰면서 고치는 개인 프로젝트라, 모든 환경에서 테스트하지는 못했습니다.
